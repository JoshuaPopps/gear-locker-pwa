Gear Locker

Every jacket, helmet, glove, and boot — what it is, what size, and what shape it’s in.

Add gear

Name is all it takes — the rest is optional. Gear with no cost entered has no value in the totals; the summary says so instead of guessing. A size left blank stays blank — sizes are typed in, never guessed.

Summary

Value is the cost you typed in, added up. Gear with no cost entered has no value in the totals — the summary counts it as unpriced instead of guessing a price.

Bikes

Bikes live in the shared Pocket Garage roster — the same b1/b2/b3 list the other apps use. Add a bike here and it is added to that roster for every app. There is no delete-bike here: roster management belongs to the landing dashboard, so a mistyped bike is removed there, not here.

Your data

No account, no server, no sync. Your gear lives in this browser's local storage. Back it up with Export — one JSON file.

Export

The backup is the whole gear locker — every bike, every item. The per-bike export below is one bike's gear, as JSON or readable plain text.

Import

Import replaces the current gear locker. Export first if you want to keep it. Gear pointing at a bike the shared roster doesn't have yet still loads — it shows under its roster key until that bike is added.

Try it out

Loads example gear in the locker so you can see the search, the totals, and what an unpriced item does to the value — before entering your own gear. The example prices are example prices only.
